# Markdown 支持与兼容性

检查日期：2026-10-04。项目保持纯前端。

## 可验证的支持范围

默认 document 模式是 CommonMark 基础解析、常用 GFM 与文档扩展的组合。现在可选择 commonmark/gfm 模式隔离扩展，并固定标准软换行；所有模式仍包含安全过滤和产品图片增强，不是 GitHub 网站渲染器的完整复制。document/obsidian 中的“标准软换行”仅改变单次回车的呈现，不会关闭插件或安全过滤。

| 范围 | 支持内容与边界 |
| --- | --- |
| 基础语法 | ATX/Setext 标题、段落、水平线、粗斜体、转义与实体、代码、嵌套列表与引用、引用式／行内链接和图片、尖括号自动链接 |
| 常用 GFM | 表格对齐、双波浪删除线、任务列表、普通 URL 和邮箱自动链接；不保证与旧 GFM 0.29 的全部输出相同 |
| 自动链接 | www、http、https、ftp 和邮箱按 GFM 规则识别；处理末尾标点、括号与类似实体的后缀；裸域名 example.com 不自动转换。自定义协议由安全策略决定 |
| 文档扩展 | 目录、脚注、定义列表、缩写、Emoji、高亮、插入线、上下标、提示块和容器、标题／图片属性、手动分页、YAML 元数据 |
| 数学与图表 | KaTeX 支持的公式和 Mermaid 图表；不是完整 LaTeX，图表失败会回退显示源码 |
| HTML | 允许的静态 HTML 经 DOMPurify 清洗；危险／未知标签、任意样式和部分属性不保留 |
| Obsidian 常用扩展 | obsidian 模式支持当前文档标题/块双链、别名、图片嵌入；跨文档笔记与笔记嵌入仍不支持 |
| 未实现方言 | Pandoc 引用文献系统、MDX/JSX、Obsidian 完整 vault 与执行式代码块等 |

解析支持不等于分页或 PDF 完全相同。合并表格和不可拆图形可能缩小；浏览器打印结果受浏览器和字体影响；批量 ZIP 使用图像 PDF。

## 换行设置

“排版 → 软换行”提供两个选项，自动保存到当前浏览器：

- 普通换行（默认，`newline`）：单次回车输出强制换行，保留已有项目行为。
- 标准软换行（`space`）：单次回车保留为软换行，通常呈现为空白，不产生 br。

行末两个空格或反斜杠仍是硬换行；空行仍划分段落。YAML 的明确值优先于界面配置：

```yaml
---
softBreaks: space
---
```

解析器按方言和换行模式分别缓存，避免并行预览／导出相互更改规则。预览、打印、图像 PDF 与批量 ZIP 使用同一解析设置。commonmark/gfm 固定标准软换行；文档中 `dialect` 的明确值优先于界面。

## 官方例集检查结果

通过应用的 `renderMarkdownToHtml`，以 `space` 模式检查完整离线例集：

| 例集 | 总例数 | 归一化结果相同 | 已登记差异 |
| --- | ---: | ---: | ---: |
| CommonMark 0.31.2 | 652 | 623 | 29 |
| cmark-gfm 0.29.0.gfm.13 的 GFM 0.29 例集 | 672 | 634 | 38 |

这里的数字不是“语法覆盖率”。比较会忽略标题锚点及其辅助空白、代码高亮 span、生成的任务列表 class、图片说明包裹和 crossorigin；将表格 CSS 对齐与 align 属性、s 与 del 视为相同语义。保留正文、代码空白、链接目标、语义属性及其他 DOM 结构。例子中的图片模拟为已上传资源，缺失图片另有测试。

已知差异逐例保存在 `tests/fixtures/spec/*-differences.json`，包括完整输入、期望、实际输出与原因：

- HTML 清洗会移除脚本、样式、未知标签或属性，部分损坏 HTML 的空白在 DOM 重解析时发生变化；链接 title 的首尾空白也可能被清洗。
- 安全策略会移除未允许协议的 href，同时保留文字。
- 在基础 CommonMark 或 GFM 基础自动链接章节中，部分普通 URL／邮箱例子的期望没有启用 GFM 扩展，应用会将其转为链接。
- GFM 0.29 的九个强调定界符例子使用较旧规则；应用采用 CommonMark 0.31.2 的规则，这些输入在新版 CommonMark 例集中的结果已验证。
- 用户 HTML 的图片未提供 alt 时，应用补充空 alt。

没有跳过差异例子。新差异、差异消失或实际结果改变均会使测试失败，需要人工核查；不得盲目更新基线。完整官方例集也不能证明所有输入都正确，项目扩展的嵌套与相互作用仍需独立回归。
