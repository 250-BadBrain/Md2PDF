## 检查范围

检查了所有项目源文件、构建配置、依赖清单，以及从上传、Markdown 解析、DOM 增强、分页预览到 PDF / ZIP 下载的完整流程。原项目没有自动化测试，原生产构建可以通过，但渲染与分页存在内容丢失。

## 已修复问题

| 问题 | 修复 |
| --- | --- |
| 正则替换图片地址，遗漏引用式图片、空格、括号和 HTML 图片 | 对解析后的图片节点统一解析资源；支持编码路径、相对目录、根目录路径和查询参数 |
| GitHub 提示块使用 textContent 重写整段，丢失加粗、链接和其他格式 | 只移除开头的提示标记及紧随其后的换行，保留子节点 |
| 分页标记在代码块内也被替换 | 使用 Markdown block rule，代码中的标记保持原样 |
| 大块内容超过一页直接裁掉 | DOM Range 拆分长正文、代码和列表；图形及超高表格行按可用高度缩小 |
| 宽代码和公式在 PDF 中横向截断 | 代码保留空白并自动换行；宽公式缩小适应页面 |
| 页末标题与正文分离、尾部分页产生空白页 | 标题与后续内容一起移动；尾部空页不输出 |
| 目录自行生成 slug，与重复标题或自定义标题 ID 不一致 | 使用标题 token 的实际 ID；目录覆盖 1–6 级标题并预留页码空间 |
| YAML 无效时仍删掉原文本，BOM 文档不识别元数据 | 无效 YAML 保留为正文；支持 BOM、CRLF 和 `...` 结束符 |
| 自定义 margin 只写在测量页，预览和导出丢失 | 将页边距保存在序列化内容、页眉和页脚上，并验证范围 |
| 页码模板替换整页 HTML，正文被误改，元数据可能成为 HTML | 只更新页眉页脚的 textContent；正文中的模板符号保持原样 |
| 同名文件和不同扩展名导出同一 PDF，ZIP 覆盖前面的文档 | 保留上传目录，并对剩余名称冲突加编号 |
| 单文件下载失败只有控制台错误 | 增加可见错误；处理上传读取失败和无 Markdown 文件的情况 |
| 资源 URL 过早撤销，图像等待无超时 | 延迟撤销旧资源；图像加载超时或失败时显示占位提示 |
| 从批量模式返回后尺寸监听失效 | 预览重新挂载时重新连接 ResizeObserver；返回后编辑首个上传文档 |
| 每次输入即启动昂贵转换 | 加入 180ms 防抖和过期结果检查 |
| 导出的所有链接不可点击 | 添加外部 URL 和目录／脚注／锚点的 PDF link annotations |
| 启动时加载全部导出依赖 | 下载时才加载 html2canvas、jsPDF 和 JSZip |
| 依赖审计报告 7 项漏洞 | 在兼容版本范围内升级依赖，固定 markdown-it / Mermaid 的安全版本下限；审计结果为 0 |

## 语法完善

新增安全内嵌 HTML、标题与图片属性、括号公式和 math 代码围栏；补齐目录及图片资源兼容性。原有脚注、定义列表、缩写、Emoji、任务列表、高亮、上下标、提示容器和语法高亮均有回归覆盖。详细写法和支持边界见 [README](../README.md) 和 [完整语法示例](../examples/syntax.md)。

HTML 使用 [DOMPurify](https://github.com/cure53/DOMPurify) 清洗；公式依据 [markdown-it-texmath](https://github.com/goessner/markdown-it-texmath) 支持的分隔符渲染。保留 KaTeX 所需的受限布局样式，并移除用户 HTML 的任意内联 CSS。

## 保留的限制

PDF 正文仍采用图像渲染，暂不可选中或搜索。极长的不可拆分表格行和图形缩小后字号可能较小。远程图片需要服务器允许跨域读取；失败时会显示提示。Markdown 方言范围见 README，不执行 MDX/JSX，也不实现完整 Pandoc 或 LaTeX。Mermaid 等第三方依赖仍包含较大的按需加载包，Vite 可能提示 chunk 大小警告。
