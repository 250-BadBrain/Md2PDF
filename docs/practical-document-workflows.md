# 图片、选页导出与嵌套表格

本轮继续保持纯前端。图片、项目、分页及 PDF 都在浏览器处理，未增加后端或上传服务。

## 图片素材

在 Markdown 编辑区粘贴截图或拖入图片，会在光标处插入引用；同名文件按大小写无关的编号避重。图片存放在当前文档同目录下的 `images/`，引用使用相对路径并编码空格、中文及括号。普通文本粘贴仍使用编辑器原有行为。

“图片”面板可独立添加素材、插入已有引用或替换图片。替换保持原路径，所以 Markdown 不需要修改；图片字节参与项目历史版本比较。异步插入期间的文本编辑会重新定位插入点，避免覆盖新输入的内容。

首次添加图片自动建立本地项目。等待“项目与图片已保存在此浏览器”后刷新，可恢复正文和图片。项目限制仍为 200 张图片、100MiB，文本上限 2Mi 字符；保存失败会显示状态。项目包包含图片，单独下载 Markdown 仅包含文本。

## 选择导出页面

在预览区展开“导出范围”，可选择全部页面、当前预览页、章节所在页面或指定页码。页码示例为 `1-3,5,8-10`，按原文顺序合并重复页码；非法格式、倒序及越界页码阻止导出并显示原因。

“当前页”采用预览中可见面积最大的页面，手机切换到编辑区时保留原位置。章节根据标题层级划分，可包含子节；按整页选择，交界页可能包含相邻章节。封面和目录不作为独立章节。

打印、图像 PDF 和实验性的直接可搜索 PDF 使用相同选页结果，保留原文页眉页脚的页码；预览继续显示全文。批量 ZIP 导出每个文档的全文。内部链接仅保留目标也在所选页面中的链接，目标页序号和混合纸张的目标坐标都按实际 PDF 重建。

## 书签与文档属性

“文档属性”面板提供标题、作者、主题和关键词。设置写入 Markdown 的 YAML，随草稿和项目保存；关键词可为列表或逗号分隔的文本。其它排版设置、注释和正文保留；无效 YAML 会提示修正，修改属性时不会更改其它设置通过 YAML alias 引用的原值。

直接下载的 PDF 根据所选页面的标题创建层级书签。完整文档的标题父链用于处理非连续选页，避免把另一章的子节挂到先前保留的章节下；重复的分页片段和生成的封面、目录标题不重复建立书签。书签定位到目标 PDF 页面，混合纸张也采用该目标页的尺寸。

原生浏览器打印的书签、文档属性和阅读顺序由浏览器决定。实验性的可搜索下载仍需要导入覆盖正文的 TTF 字体；字体只保留在当前页面，公式和图形保持图像。

## 嵌套长表格

列表、引用、提示块和文档容器内的长表格按行或相连 rowspan 行组分页，保持正常字号，重复表头及外层提示标题。表格前后的正文只保留一次；列表编号、源码定位和折叠提示状态保留。原始表格 ID 只保留第一次出现的位置，避免链接目标重复。

普通超高单行继续拆分内容；不可拆的超高合并行组仍可缩小，后续正常行恢复正常字号。页底脚注参与可用高度计算；启用宽表横向页时，外层提示仍保留，表格后的正文恢复原方向。空任务项的复选框也保留，不因缺少可见文本被跳过。

## 验证内容

142 项单元测试覆盖图片原子校验、引用解析、异步插入、范围解析、标题父链、YAML 属性及面板焦点；官方 1,324 个示例及已登记差异保持不变。浏览器验证包括图片自动保存/替换/历史恢复、手机当前页、所选打印页、PDF.js 的实际元数据/书签/链接坐标，以及压缩构建的离线流程。

实际导出验图使用 10 页 A5 文档，核对 72 行、24 个三行合并单元格、9 个表格片段和重复表头/标题，正文首尾完整且没有整体缩小。图像 PDF 和原生打印 PDF 均经过文字或结构检查及代表页渲染检查，既有视觉基线未修改。
