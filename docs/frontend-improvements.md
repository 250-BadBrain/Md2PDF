## 导出反馈与浏览器

打印保存说明在预览中可见；打印流程只报告对话框调用，不报告 PDF 已保存。图片、公式、Mermaid 错误和内容缩放提示集中显示，无法解析的公式保留源码和具体错误。

图像 PDF 显示逐页进度，批量 ZIP 显示当前文件。支持取消：在当前分页／画布任务完成或取消检查点退出，取消后不下载未完成结果，测量 DOM 会清理。单次 html2canvas 和 ZIP 压缩无法在内部立即打断。

已验证 Chromium 和 WebKit 的实际渲染、打印 iframe 准备与调用，以及 Chromium 的 PDF 文字／物理尺寸。WebKit 测试不是 Safari 本体或系统打印对话框测试。本机 Playwright Firefox 155 启动返回 `spawn UNKNOWN`，重试仍失败，Firefox 未验证。保留独立的 `npm run test:firefox`，无需修改应用代码即可在可运行的环境验证。

## 文档排版

“排版”新增经典、书籍、紧凑主题，可选封面与脚注位置。书籍主题采用衬线标题；紧凑主题减小段落间距。封面使用标题、作者、日期，占用一页，计入页码；标题未指定时使用首个一级标题。

脚注默认仍在文末。选择“靠近首次引用”后，脚注放在首次引用的正文块之后，保留编号、ID 和回链；不能保证页底位置，超长正文块或脚注仍可能跨页。这一设置不复制同一脚注定义。

含 rowspan 的表格按相连的行组分页，重复表头，保持合并关系；普通行组维持字号。只有高于整页的行组才缩小。图片和说明沿用 figure 的原子分页。表格包含不规范 HTML 时，浏览器仍可能自动调整其 DOM。

```yaml
---
title: 文档标题
author: 作者
cover: true
theme: book
footnotes: near-reference
---
```

这些选项也可在界面设置并保存；文档 YAML 的明确值优先。

## 编辑与恢复

正文、当前文件名和路径自动保存在此浏览器，刷新后恢复。草稿不保存图片或整个批量文件夹；重新打开后，本地图片需重新上传。容量上限按正文 2Mi 字符限制，实际浏览器存储配额可能更低；保存失败时显示提示，不覆盖先前可恢复的草稿。清除草稿不会清空当前编辑内容，继续修改时会重新保存。

支持文字查找、定位下一个、替换当前、全部替换；采用区分大小写的字面匹配，不把查找内容解释为正则。Ctrl/Cmd+F 打开查找工具，Markdown 下载保留原始文本。可选同步滚动采用双向滚动比例，不是按源代码行精确映射。

## 性能与离线

正文超过 60,000 字符时，纯解析、高亮和公式转换由独立模块 Worker 完成；HTML 清洗、图片、Mermaid 和依赖 DOM 的分页留在主线程。过期解析终止 Worker；Worker 无法启动时回退到本地解析。小文档保持原来的轻量路径。

图像导出逐页创建测量与截图 DOM，使用后卸载，画布编码后释放尺寸。jsPDF 最终结果与批量 ZIP 仍需保存在内存，超大批量仍可能触及浏览器内存上限。

生产版提供安装清单和版本化 Service Worker。首次需联网等待完整静态缓存，之后支持离线重载、公式、Mermaid、图像 PDF 与 ZIP 依赖。缓存只包含构建清单中的应用代码、字体和图标，不保存用户文档、blob 图片、API 或远程资源。离线草稿是独立的浏览器本地存储。

离线功能需要 HTTPS 或 localhost，开发模式不注册 Service Worker。更新在旧页面全部关闭后激活，避免旧页面混用新模块；界面显示更新准备状态。删除浏览器站点数据会同时移除草稿、设置和离线缓存。安装入口是否提供由浏览器决定。

## 验证方式

```sh
npx playwright install chromium webkit
npm test
npm run build
npm run test:browser
```

生产离线测试启动构建后的静态预览、等待缓存激活、切断网络并验证渲染与下载。离线测试需先构建。Windows 可通过 `PLAYWRIGHT_CHANNEL=msedge` 使用已有 Edge 跑 Chromium 测试。Firefox 单独执行：

```sh
npx playwright install firefox
npm run test:firefox
```

官方兼容性例集仍检查全部 1,324 例，差异基线没有放宽；原有分页截图基线保持不变。源码解析与 DOM 增强已分为 `markdown-parser.ts` 与 `markdown.ts`，防止 Worker 引入 DOM 或 Mermaid 依赖。

本次结果：26 项单元测试、27 项默认浏览器测试通过，生产构建与离线专项复核通过，依赖审计零漏洞。新增封面与靠近引用的脚注截图已人工检查；原有视觉基线未更新。Firefox 独立测试因浏览器启动失败未能执行。
